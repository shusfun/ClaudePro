CLAUDEPRO / WINDOWS ENVIRONMENT SWITCHER

切换环境，随时回到原点。

Windows x64 · 版本 0.1.0 · Wails 3

保存真实原值，逐项验证，手动还原。支持 Claude Code CLI 与 Claude Desktop。

开始使用环境检测修改范围恢复与冲突客户端故障处理构建验证

选择地区模板，预览后切换

  1. 双击项目 bin\claudepro.exe。以普通用户身份运行界面；修改系统时区时才出现 UAC。
  2. 首页选择美国西部、美国东部、英国、德国、日本或新加坡模板，一次配齐时区、区域格式和国家地区。选择只影响预览，不修改 Windows；点击“切换环境”时才保存目标并执行，无需额外保存。模板缺少本机 Windows 必需选项时会禁用并显示原因。
  3. 保存工作并关闭 Claude CLI 和 Desktop 会话。检查首页当前值、目标值与差异，点击“切换环境”。若检测到进程，关闭后重新点击，应用会再次检查。
  4. 成功后自行选择“启动 CLI”或“启动 Desktop”。不会自动启动或强制结束现有进程。
  5. 结束工作并关闭 Claude 后，点击“恢复原环境”。退出 ClaudePro 不会自动恢复 Windows 设置。

界面与主题

界面采用 MiGate 的蓝色拟物组件。顶部主题按钮循环切换浅色、深色、跟随系统，默认跟随系统，并记住你的选择。左侧“收起导航”保留图标导航；窄窗口改用顶部菜单打开导航抽屉。主题与折叠状态仅保存在 ClaudePro 的本地界面存储，不修改 Windows 主题。

“自定义区域设置”展开可搜索的选择器，支持显示名称、代码及 Windows 时区 ID 搜索，忽略大小写。使用方向键和 Enter 选择，Escape 关闭；输入搜索词不会改变已选值。首页与设置页共享草稿，切换页面不会丢失，关闭应用前尚未保存的草稿不会持久化。客户端路径和工作目录仍在设置页保存；首页切换只保存目标，不保存未提交的客户端路径。弹窗限制焦点在内部，关闭后返回入口；退出提醒默认聚焦“留在应用”。恢复冲突必须逐项选择，提交期间不能关闭弹窗或重复提交。成功结果短暂提示，错误与恢复警告持续显示。

这些是系统全局或当前用户设置，也会影响其他应用。区域切换不等于 IP、账号地区或设备指纹切换，不构成避免封禁的保证。

先体验操作：运行 .\bin\claudepro.exe --demo。模拟模式使用独立文件，不修改 Windows，也不启动真实 Claude；检测使用固定模拟数据，不查询网络。

本机检查与手动网络检测

首页显示检测摘要；侧栏“环境检测”展示三项实际设置与所选目标的差异、客户端是否可用、正在运行的 Claude 会话、恢复记录和配置冲突。启动、刷新、切换及恢复后自动更新，每次显示检测时间。目标尚未应用导致的差异只记为信息，不判为故障。

只读显示当前用户 Internet Settings 的手动代理启用状态、PAC 是否配置，以及代理环境变量是否存在；不展示代理地址、密码或令牌。这些配置提示不代表 Claude 最终使用的路由。

根据出口推荐地区模板

首页模板上方点击“检测并推荐地区”，展示出口 IP、城市、州 / 省和 IANA 地理时区。美国的 America/Los_Angeles 推荐“美国西部”，America/New_York 及明确的东部时区别名推荐“美国东部”。按地理时区判断，不按会随夏令时变化的 UTC 偏移判断。

检测到美国中部、山地、阿拉斯加、夏威夷等时区，或服务未返回时区时，不强行猜测美东 / 美西，提示自定义。英国、德国、日本、新加坡按国家匹配现有模板，其他国家提示自定义。

“采用推荐”只填充目标预览，不保存配置、不修改系统；点击“切换环境”才执行。有未恢复记录时仍禁止更换目标。本机缺少必需选项时不能采用该模板。结果显示来源和时间，更换代理后待短时缓存到期，再点击“重新检测并推荐”。两个来源的出口 IP、国家或美东 / 美西模板判断冲突时，停止推荐并显示来源详情；单源可用时注明未交叉确认。城市不同但时区与模板判断相同，不算模板冲突。IP 定位是近似结果，不能说明人的实际位置或 Claude 请求必然使用的出口。

检测网络出口

点击按钮才向 GeoJS、ipwho.is、ipinfo、ipapi 的 HTTPS 接口发起请求，服务会接收到本次请求的出口 IP。采用有限并发、错峰查询和失败回退，优先使用前面的来源；收集两份可用结果后取消其他请求。展示 IP、国家地区、ASN、运营商、数据来源、检测时间和代理模式，并与选定目标国家比较。

网络请求采用 Go 的环境变量代理规则（HTTPS_PROXY / HTTP_PROXY / NO_PROXY 及对应小写形式）；ALL_PROXY 仅显示配置存在性，不作为 Go 默认 HTTP 请求的代理。不会自动模拟 Windows PAC 或 Claude 专属代理。检测出口可能不同于 Claude 经代理分流后的出口。

整体最多 10 秒，单源最多 4 秒；429 自动跳过并按 Retry-After 退避（未提供时默认 5 分钟），其他来源继续检测。IP 和国家有效即可展示，缺少 ASN / 运营商显示“未知”。只有所有来源均不可用才显示失败。成功结果缓存 60 秒，失败冷却 30 秒，按钮显示剩余时间，期间不重复发请求。没有后台轮询，结果不写入文件，仅保留在当前会话。修改代理后应重新检测；界面会保留上次结果的时间。

页面提供 check-cc 与 MyIP 外部入口，在默认浏览器打开。浏览器语言、WebRTC 和指纹结果只说明该浏览器环境，不能直接代表 CLI 或 Desktop。

检测提供事实和差异，不生成封号风险分；国家一致不意味着账号安全或符合服务地区资格。原有代理、DNS、IPv6、凭据和设备标识均不修改。

实际修改项

项目范围和操作恢复依据
系统时区系统全局。独立 UAC 辅助进程验证 Windows 时区 ID，再调用 tzutil。实际时区 ID，包括原有的 _dstoff 后缀。
区域格式当前用户，Set-Culture。HKCU\Control Panel\International 直接字符串值快照，包含自定义日期、数字、货币等。
国家地区当前用户，Set-WinHomeLocation。HKCU\Control Panel\International\Geo 直接字符串值快照。

不修改显示语言、输入法、首选语言列表、代理、IPv6、DNS、账号凭据、设备 ID 或浏览器指纹。恢复后通知 Windows 设置变化；其他应用可能仍需重启。

已与目标相同的项目不重写，保留自定义格式。恢复只处理本次实际进入修改流程的项目。

备份、还原与冲突

正式数据：%LOCALAPPDATA%\ClaudePro；模拟数据：%LOCALAPPDATA%\ClaudePro-Demo。

文件用途
config.json目标环境、工作目录、手动客户端路径。
journal.json当前或最近一次原始值、目标值、步骤意图、回读值、状态、日志。
history\*.json开始下一次切换时归档旧记录。恢复成功后当前日志仍保留。

采用版本化 JSON、临时文件、刷新落盘和原子替换。切换顺序：时区 → 区域格式 → 国家地区；恢复顺序相反。每步写入前记录意图，写入后回读。

任何步骤失败会尝试逆序回滚。备份无法写入、回读失败、恢复权限被取消或结果不明时，停止并保留恢复记录。恢复时比较原始值、本工具最后回读值与当前值，外部变化或未验证写入会显示冲突：

  • 恢复原始值：明确授权恢复该项目的备份值。
  • 保留当前值：不覆盖外部修改，日志记录主动放弃此项还原。“恢复流程完成”不表示保留项目也回到了原值。
  • 对话框打开后配置再次变化，旧选择失效，需要重新检查。

存在未恢复记录时，禁止新切换和目标变更，重复点击不会覆盖原始备份。退出时提示一次，保留环境退出后，下次打开可继续恢复。

客户端发现与启动

CLI：用户 PATH 中发现 claude.exe 或 npm claude.cmd / claude.ps1。设置支持浏览文件和工作目录。启动可见的新 PowerShell 终端，沿用现有环境变量和凭据，不修改登录信息。

Desktop：优先从 Claude MSIX 包清单读取应用 ID，通过 Windows AppsFolder 激活。普通安装检测常见本地路径，也可浏览选择 EXE。已有普通安装窗口时只请求激活；仅有后台进程而没有窗口时，提示从托盘打开，不重复创建进程。

MSIX 建议将手动路径留空。手动路径必须为现存绝对路径，空格和中文路径作为结构化数据传递。启动客户端保持普通权限。

切换或恢复前关闭全部 Claude 会话，包含托盘中的 Desktop。Windows 可能限制抢焦点，可从任务栏切换窗口。工具不会强制结束进程。

故障处理

UAC 取消、执行失败或应用中断

重新打开应用并“刷新状态”。显示“需要恢复”时，关闭 Claude 后点击“恢复原环境”。未验证写入将显示为冲突供你选择。不要清理日志或通过删除备份来解除切换限制。

备份损坏

应用停止修改并保留损坏文件。先复制整个数据目录，再检查 journal.json、残留 .pending-* 和自己的备份副本。历史文件属于之前的切换，不能直接当作本次原值。原始数据无法找回时无法保证精确还原；请使用自己的系统备份或按核实过的原值人工调整。

仅 config.json 损坏

有效 journal.json 仍提供恢复入口。先完成恢复，关闭应用后备份并重命名损坏的 config.json，再重新配置目标。不要删除 journal.json。

人工核对

tzutil /g 查看时区；Windows“时间和语言 → 语言和区域”核对地区及区域格式。精确的自定义格式位于日志 original.culture.data，对应 International 注册表直接值；original.region.data 对应 Geo。人工修复前保留副本，不套用其他机器的注册表。

无法打开界面

缺少可用 WebView2 时会出现中文提示。安装 Microsoft Edge WebView2 Evergreen Runtime 后重试。EXE 为未签名便携版。网络检测无法连接时，可以直接使用本机检查及切换恢复功能。系统策略禁止 PowerShell、注册表写入或 UAC 时会报告错误，按本机管理策略处理。

只读诊断

Start-Process .\bin\claudepro.exe -ArgumentList '--diagnose' -WindowStyle Hidden -Wait -RedirectStandardOutput .\bin\diagnose.json

诊断包括实际环境、支持选项、客户端路径和运行进程，不写入设置。分享前可自行移除用户名及个人路径。
